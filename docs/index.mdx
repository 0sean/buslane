Buslane ingests timetable and fare data from the [Bus Open Data Service](https://data.bus-data.dft.gov.uk/) and serves it as an API, making it possible to use in modern web apps easily.

It powers timetable and fare data in [bus.rip](https://bus.rip/) and [Metro](https://metro.transit.fyi/).
