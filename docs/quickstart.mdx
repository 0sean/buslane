---
title: "Get started"
description: "Host your own Buslane instance"
---

Once you've cloned [the repo](https://github.com/0sean/buslane) (and assuming you have Docker installed):

<Steps>
  <Step title="Make a copy of the `.env.example` file, and set it up">
    Mainly, you’ll need to set an auth token for accessing the API, and directories to store data in.<br /><br />You should ensure the UID/GID you have set owns the data directories (use `chown` if not).

    ```shellscript
    cp .env.example .env
    ```
  </Step>
  <Step title="Build the Docker images">
    ```shellscript
    docker compose build
    ```
  </Step>
  <Step title="Run an initial import">
    ```shellscript
    # Timetables import
    docker compose --profile jobs run --rm --no-deps importer
    # Fares import
    docker compose --profile jobs run --rm --no-deps fares-importer
    ```
  </Step>
  <Step title="Start the API server">
    ```shellscript
    docker compose up -d --no-build api
    ```
  </Step>
  <Step title="Install the import service (runs daily imports)">
    ```shellscript
    sudo install -m 644 deploy/systemd/buslane-import.service deploy/systemd/buslane-import.timer /etc/systemd/system/
    sudo systemctl daemon-reload
    sudo systemctl enable --now buslane-import.timer
    systemctl list-timers buslane-import.timer
    journalctl -u buslane-import.service
    ```
  </Step>
</Steps>
